# Folder Galeri Foto Outlet Dua SiSi Laundry

Folder ini digunakan untuk menyimpan foto-foto suasana outlet yang ditampilkan pada bagian **3D DriftWall Gallery** di Landing Page website.

### 📸 Berapa Jumlah Foto yang Dibutuhkan?
- **Rekomendasi Ideal**: **8 sampai 12 Foto** (Minimal 6 foto).
- Dengan 8–12 foto, 6 kolom paralaks di website akan terisi penuh, mengalir berputar (*infinite scroll*) secara variatif tanpa terlihat berulang terlalu cepat.

### 📐 Rekomendasi Format & Ukuran:
1. **Rasio / Orientasi**: Landscape horizontal (**16:9**, **3:2**, atau **4:3**).
2. **Resolusi**: Lebar sekitar **800px – 1200px** (tidak perlu terlalu besar seperti 4K agar loading web sangat cepat dan hemat kuota pelanggan).
3. **Format File**: `.jpg`, `.jpeg`, `.png`, atau `.webp`.
4. **Ukuran File**: Disarankan di bawah **300 KB – 500 KB per foto** (bisa dikompres lewat TinyPNG jika ukuran foto kamera terlalu besar).

---

### 🏷️ Contoh Penamaan File Foto:
Anda dapat menamai file foto secara berurutan, misalnya:
- `foto-1.jpg` (Suasana mesin koin / washer & dryer)
- `foto-2.jpg` (Area ruang tunggu / lounge WFL - Work From Laundry)
- `foto-3.jpg` (Meja kasir & display deterjen / softener)
- `foto-4.jpg` (Proses setrika uap & packing rapi)
- `foto-5.jpg` (Tampak depan outlet / fasad toko)
- `foto-6.jpg` (Fasilitas free wifi / stopkontak)
- `foto-7.jpg` (Keranjang laundry & timbangan)
- `foto-8.jpg` (Hasil cucian terlipat rapi)
