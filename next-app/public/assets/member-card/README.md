# Digital Member Card & Stamp Assets

Folder ini digunakan untuk menempatkan file desain SVG / Gambar untuk fitur **Digital Member Card & Loyalty Stamp**.

### 📁 Penamaan File yang Disarankan:
1. `card-frame.svg` atau `card-template.svg` — Desain background / bingkai kartu member digital.
2. `stamp-active.svg` — Ikon stempel saat slot sudah terisi (misal: stempel logo / cap laundry berwarna emas/teal).
3. `stamp-inactive.svg` — Ikon stempel saat slot masih kosong / abu-abu (misal: lingkaran garis putus-putus atau cap transparan).
4. `stamp-reward.svg` — Ikon reward slot terakhir (misal: gratis cuci 1x / koin emas / hadiah diskon).

---
*File di folder ini dapat diakses langsung di Next.js melalui path: `/assets/member-card/[nama-file.svg]`*
